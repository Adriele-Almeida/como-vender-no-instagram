# Como vender no Instagram

Guia prático de Adriele Almeida para vender no Instagram no segundo semestre de 2026. Leitura por capítulos, com exercícios do método: bio em três segundos, métrica de interação, técnica da semântica e checklist do perfil.

## Rodar

```bash
npm install
npm run dev
```

O app sobe em `http://localhost:8080`.
